# 태양 복사 에너지 실험실

고등학교 1학년 통합과학 「지표와 대기의 열 출입」 수업용 인터랙티브 시뮬레이터입니다.
태양 복사 에너지가 대기와 지표를 만날 때 일어나는 **산란·반사·흡수·굴절**을, 조건을 바꾸며 직접 확인할 수 있습니다.

## 기본 모드와 심화 탐구

화면 위쪽에서 **기본 모드**(처음 열 때)와 **심화 탐구**를 바꿀 수 있습니다. 바꿔도 조건과 시뮬레이션 상태는 그대로 유지됩니다.

- **기본 모드**: 대표 광선 몇 개만 움직이고, 핵심 조작 도구·짧은 원리 설명·관찰 질문 하나만 보입니다(교실 대형 화면 시연용).
- **심화 탐구**: 추가 조건, 상세 수치·그래프, 비교 기능, 심화 설명이 함께 보입니다.

| 탭 | 기본 모드 | 심화 탐구에서 추가 |
|---|---|---|
| ① 산란 | 태양 고도 → 대기 통과 거리, 백색광(세 색 묶음)의 산란, 산란된 파란빛이 눈으로 오는 경로, 태양·하늘의 색 | 먼지·에어로졸, 관측 방향·시선 고도, 관측자 시야, 파장별 직접 도달 비율 |
| ② 반사 | 두 지표 비교(눈·풀·젖은 흙·모래사장), 입사 100의 반사·흡수 화살표와 막대 | 한 대상 보기, 구름(반사·흡수·투과), 100개 묶음 누적 개수, 학습지 표 |
| ③ 흡수 | 대표 광선(자외선·가시광선·적외선)의 흡수 위치, 온도계(정도만 표시) | 오존·수증기 양, 지표 반사율, 흡수 스펙트럼, 상대 온도 그래프, 에너지 출입 수치 |
| ④ 굴절 | 대기 있음/없음, 태양 고도, 직선 경로와 휘는 경로, 실제 효과 크기 | 대기 밀도(%), 파면, 실제 굴절량 그래프·계산값, 과장 배율 |
| ★ 여행 | 학습지 개념도를 8단계로 완성(이전/다음, 전체 자동 재생) | (같음) |

## 구성

| 탭 | 조작 | 관찰 |
|---|---|---|
| ① 산란 | 태양 고도, 먼지·에어로졸 양, 관측 방향(하늘/태양), 시선 고도, 표시할 파장 | 대기 통과 거리(공기량), 파장별 직접 도달 비율, 관측자 시야의 하늘·태양 색 |
| ② 반사 | 지표·구름 종류(학습지 6종), 학습지 범위 안의 반사율, 두 대상 비교 | 입사 100에 대한 반사·흡수(구름은 투과·흡수) 막대그래프와 에너지 흐름 |
| ③ 흡수 | 비추는 파장 영역, 오존 양, 수증기 양, 지표 반사율 | 파장별 흡수 스펙트럼, 성분별 흡수 에너지, 오존층·수증기층·지표의 온도 변화 |
| ④ 굴절 | 대기 밀도 차이, 태양의 실제 고도 | 휘어지는 빛의 경로, 실제 위치와 겉보기 위치, 고도별 위치 차이 그래프 |
| ★ 태양 복사 에너지의 여행 | 이전/다음 단계 | 입사 → 산란 → 구름 반사 → 대기 흡수 → 지표 도달 → 지표 반사·흡수 → 굴절 |

모든 탭에 재생·일시정지(스페이스바)·초기화·재생 속도, 원인→과정→결과 설명, 조건 변화 안내, 탐구 질문(정답 확인)이 있습니다. 기본 모드에서는 탐구 질문이 조작 패널 아래에 있어 스크롤 없이 보입니다.
제목을 누르면 처음 화면(① 산란)으로 돌아갑니다.

## 과학 모형 (학습용 단순화)

- **산란**: 공기 분자의 레일리 산란 광학적 두께(Hansen & Travis 근사식), 먼지·에어로졸은 파장 의존성이 약한 옹스트룀 식(α = 1.3)과 앞쪽으로 치우친 위상 함수로 따로 계산합니다. 공기량은 Kasten & Young 식, 하늘색은 평행평면 대기의 단일 산란 복사휘도를 CIE 등색 함수로 색 변환해 그립니다. 단면 그림의 대기 두께는 과장했고, 수치는 실제 공기량으로 계산합니다.
- **반사**: 반사율은 첨부 학습지 값(두꺼운 구름 70~90%, 얇은 구름 25~30%, 눈 50~90%, 젖은 흙 15~25%, 풀 5~25%, 모래사장 20~40%)을 그대로 사용합니다. 빛 묶음 100개마다 반사·흡수(·투과) 개수가 막대·화살표의 수치와 정확히 같도록 배분합니다. 지표는 입사 100 = 반사 + 흡수, 구름은 반사 + 흡수 + 투과이며, 구름의 흡수율은 학습지에 없어 대표값(두꺼운 구름 약 10%, 얇은 구름 약 3%)을 씁니다.
- **흡수**: 대기 밖 태양 복사(5778 K 흑체 + 자외선 보정), 오존 흡수 단면적을 단순화한 표, 수증기 흡수대(0.72~2.7 μm)를 적분합니다. 기본 조건에서 오존 약 2%, 수증기 약 13%를 흡수합니다. 온도는 `dT/dt = k·(흡수 에너지) − T/τ`의 단순 모형(세 곳의 열용량이 같다고 가정)이므로 실제 °C가 아니라 **상대값**(기본 조건에서 지표의 최종값 = 100)으로만 표시합니다. 기본 모드는 '거의 그대로/조금 상승/상승/많이 상승'으로만 보여 줍니다.
- **굴절**: 고도에 따라 지수적으로 줄어드는 굴절률 분포에서 광선 방정식을 수치 적분하므로 경로가 층 경계에서 꺾이지 않고 연속적으로 휩니다. 그림의 휘어짐은 크게 과장했으며, 그림의 각도는 겉보기 고도로 표시하지 않습니다. 실제 위치와 겉보기 위치의 차이는 Sæmundsson 대기차 식(표준 대기, 밀도에 비례)으로 계산하고(예: 고도 0° 약 29′, 10° 약 5′), 그림이 몇 배 과장되었는지도 함께 표시합니다.
- **종합 모드**: 대표 광선이 정해진 경로를 따라 단계별로 개념도를 완성합니다. 단계는 관찰 순서일 뿐 실제 발생 순서가 아니며, 굴절은 대기를 지나는 동안 계속 일어나므로 7단계에서 광선 하나를 골라 따로 관찰합니다. 입사 에너지 100을 과정별 비율로 나누지 않습니다.

## 실행·배포

빌드 과정이 없는 정적 웹앱입니다(HTML·CSS·JavaScript, Canvas).

- 로컬: `index.html`을 브라우저로 열거나, 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속
- GitHub Pages: 저장소 Settings → Pages → Branch를 `main` / `(root)`로 지정
- Vercel: 저장소를 Import하고 Framework Preset을 `Other`로 두면 그대로 배포됩니다.

외부 서버나 API를 쓰지 않으며, 개인정보를 저장하거나 전송하지 않습니다. (Pretendard 글꼴만 CDN에서 불러오며, 연결이 없으면 시스템 글꼴로 표시됩니다.)
