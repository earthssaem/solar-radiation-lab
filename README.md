# 태양 복사 에너지 실험실

고등학교 1학년 통합과학 「지표와 대기의 열 출입」 수업용 인터랙티브 시뮬레이터입니다.
태양 복사 에너지가 대기와 지표를 만날 때 일어나는 **산란·반사·흡수·굴절**을, 조건을 바꾸며 직접 확인할 수 있습니다.

## 기본 모드와 심화 탐구

화면 위쪽에서 **기본 모드**(처음 열 때)와 **심화 탐구**를 바꿀 수 있습니다. 바꿔도 조건과 시뮬레이션 상태는 그대로 유지됩니다.

- **기본 모드**: 대표 광선 몇 개만 움직이고, 핵심 조작 도구·짧은 원리 설명·관찰 질문 하나만 보입니다(교실 대형 화면 시연용).
- **심화 탐구**: 추가 조건, 상세 수치·그래프, 비교 기능, 심화 설명이 함께 보입니다.

제목을 누르면 처음 화면(① 산란)으로 돌아갑니다. 맨 아래 푸터에 제작자와 ‘연경쌤의 지구과학 실험실 둘러보기 →’ 링크(새 탭)가 있습니다.

## 과학 모형 (학습용 단순화)

- **산란**: 모든 빛은 화면 모서리의 큰 태양 원반 표면에서 출발해 같은 방향으로 나아가는 평행광선(미리 그려 둔 경로) 위에서만 움직이고, 산란광은 대기 속 산란 지점에서만 생겨 여러 방향으로 퍼집니다(일부는 대기 밖으로 나감). 공기 분자의 레일리 산란 광학적 두께(Hansen & Travis 근사식), 먼지·에어로졸은 파장 의존성이 약한 옹스트룀 식(α = 1.3)과 앞쪽으로 치우친 위상 함수로 따로 계산합니다. 공기량은 Kasten & Young 식, 하늘색은 평행평면 대기의 단일 산란 복사휘도를 CIE 등색 함수로 색 변환해 그립니다. 단면 그림의 대기 두께는 과장했고, 수치는 실제 공기량으로 계산합니다.
- **반사**: 학생은 대상의 종류만 고르고, 반사율은 대상별 대표값(학습지 범위 안)이 자동 적용됩니다. 반사율은 대상의 상태와 관측 조건에 따라 범위 안에서 달라질 수 있다는 점을 함께 안내합니다. 반사율 범위는 첨부 학습지 값(두꺼운 구름 70~90%, 얇은 구름 25~30%, 눈 50~90%, 젖은 흙 15~25%, 풀 5~25%, 모래사장 20~40%)을 그대로 사용합니다. 빛 묶음 100개마다 반사·흡수(·투과) 개수가 막대·화살표의 수치와 정확히 같도록 배분합니다. 지표는 입사 100 = 반사 + 흡수, 구름은 반사 + 흡수 + 투과이며, 구름의 흡수율은 학습지에 없어 대표값(두꺼운 구름 약 10%, 얇은 구름 약 3%)을 씁니다.
- **흡수(지구 대기의 선택적 흡수)**: 태양(5800 K)과 지구(288 K)의 흑체 스펙트럼을 쓰며 최대 에너지 파장은 빈의 변위 법칙(λmax = 2898 μm·K ÷ T: 약 0.50 μm, 약 10.1 μm)과 일치합니다. 스펙트럼 비교는 실제 세기(표면의 분광 복사 방출도, W/(m²·μm))로 그립니다: 학습지처럼 두 그래프를 각자의 세로 눈금으로(태양 최대 약 8.4×10⁷, 지구 약 26), 또는 하나의 로그 눈금으로. 태양 복사 장면의 그래프는 지구 대기 위에 도달하는 세기(최대 약 1,800), 지구 복사 장면은 지표의 방출 세기입니다. 오존·산소, 수증기, 이산화 탄소, 메테인, 산화 이질소의 흡수는 대표 흡수대 모양을 단순화한 **정성적 곡선**이며 흡수율(%) 수치는 표시하지 않습니다. 태양·지구 복사는 여러 파장이 함께 진행하는 빛 다발로 그립니다. 다발 속 각 줄기는 자기 파장에서의 흡수 정도와 같은 확률로 흡수되고, 흡수되는 순간 그래프에 그 파장이 표시되어 그래프와 장면이 일치합니다. 지구 복사에서 흡수된 에너지는 여러 방향으로 재방출되고(지표 방향만이 아님) 그 일부가 지표로 돌아옵니다(온실 효과). 대기의 창(8~13 μm)은 흡수가 약하지만 9.6 μm 오존 흡수 등이 있어 완전히 투명하게 그리지 않습니다. 온도는 수치 없이 정성적으로만 표현합니다.
- **굴절**: 고도에 따라 지수적으로 줄어드는 굴절률 분포에서 광선 방정식을 수치 적분하므로 경로가 층 경계에서 꺾이지 않고 연속적으로 휩니다. 그림의 휘어짐은 크게 과장했으며, 그림의 각도는 겉보기 고도로 표시하지 않습니다. 실제 위치와 겉보기 위치의 차이는 Sæmundsson 대기차 식(표준 대기, 밀도에 비례)으로 계산하고(예: 고도 0° 약 29′, 10° 약 5′), 그림이 몇 배 과장되었는지도 함께 표시합니다.
- **종합 모드**: 대표 광선이 정해진 경로를 따라 단계별로 개념도를 완성합니다. 단계는 관찰 순서일 뿐 실제 발생 순서가 아니며, 굴절은 대기를 지나는 동안 계속 일어나므로 7단계에서 광선 하나를 골라 따로 관찰합니다. 입사 에너지 100을 과정별 비율로 나누지 않습니다.

## 실행·배포

빌드 과정이 없는 정적 웹앱입니다(HTML·CSS·JavaScript, Canvas).

- 로컬: `index.html`을 브라우저로 열거나, 폴더에서 `python3 -m http.server` 실행 후 `http://localhost:8000` 접속
- GitHub Pages: 저장소 Settings → Pages → Branch를 `main` / `(root)`로 지정
- Vercel: 저장소를 Import하고 Framework Preset을 `Other`로 두면 그대로 배포됩니다.

외부 서버나 API를 쓰지 않으며, 개인정보를 저장하거나 전송하지 않습니다. (Pretendard 글꼴만 CDN에서 불러오며, 연결이 없으면 시스템 글꼴로 표시됩니다.)
